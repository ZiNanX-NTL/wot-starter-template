# 目标

为 Wot Starter 增加统一的登录态路由拦截能力，使页面可以声明是否需要登录，并支持黑名单、白名单两种策略。未登录用户访问受保护页面时保存原始地址，登录完成后可回跳；已登录用户访问登录页时跳转到回跳地址或首页。

# 非目标

- 本变更不实现具体的账号密码、短信或微信账号登录接口。
- 本变更不改变现有 API 请求鉴权拦截器的业务错误处理。
- 本变更不引入仅浏览器可用的存储或路由 API。

# 影响范围

- 新增登录状态及 Token 过期判断的可复用模块。
- 扩展 `definePage` 页面元信息，支持页面级登录配置。
- 在 `src/router/index.ts` 注册统一前置拦截器，并保留现有演示守卫行为。
- 新增登录页作为默认公共页面；H5 与微信小程序采用相同策略，微信端额外处理小程序启动/页面栈限制。

# 验收标准

- 黑名单模式下仅配置为需要登录或命中黑名单的页面被拦截；白名单模式下仅白名单页面免登录。
- Token 缺失或已过期视为未登录；过期 Token 被清理。
- 未登录访问受保护页面会跳转登录页，并携带编码后的 `redirect` 原始地址。
- 已登录访问登录页会跳转 `redirect`，无有效回跳时跳转首页。
- 微信小程序端不会使用 `window`、`location` 等浏览器专属 API，且回跳参数在页面栈场景下可恢复。
- `pnpm type-check` 与 `pnpm lint` 通过。
